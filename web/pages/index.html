The method

Published finance, done carefully.

Breeden–Litzenberger (1978): the second derivative of option prices across strikes is the market's probability density. The hard part is the cleaning and smoothing that make it stable on real quotes.

Watch each step live →
  1. CleanOut-of-the-money quotes only; stale and too-wide quotes dropped; the forward from put-call parity.
  2. SmoothImplied volatility per strike, fitted with a spline weighted by each quote's spread.
  3. DifferentiateA 601-point density per expiry, kept free of negative probability.
  4. PaintPercentile bands into the future, widening with the square root of time.

Questions

Good to know.

Is this a forecast?

No. It is the risk-neutral distribution: what the options market charges for each outcome. It includes risk premia, so it is the market's price of the odds, not a guarantee of real-world odds.

What do I need?

A TrendSpider account with access to options data (OPRA), a Daily chart, and a ticker with listed US options. Other timeframes and tickers without options show a clear message instead of a chart.

How is it different from an expected move?

An expected move is one number turned into a symmetric range. Implied uses every liquid strike to recover the whole shape: which tail is fatter, how fat it is, and whether the market is pricing two separate outcomes.

Does it cost anything or send my data anywhere?

No. It is one open-source file that runs inside TrendSpider. There is no server and no API key. The pages on this site also run entirely in your browser.

Has it been tested inside TrendSpider?

The script follows TrendSpider's published scripting rules, and every page here runs it against a stand-in for that runtime. A short checklist for confirming it on a live chart is in the verification guide on GitHub.
