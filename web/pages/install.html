Implied/Install

Install

One file, pasted into TrendSpider. About a minute.

Steps

01

Copy

Copy the script, or download implied.js.

Copy the scriptDownload
02

Paste

In TrendSpider, open the Custom JS indicator editor, create a new indicator, paste, and save.

03

Add

Add Implied to a Daily chart of any ticker with listed US options.

Requirements

DailyThe timeframe it runs on; others show a message
OPRATrendSpider's real-time options data subscription
OptionsA ticker with listed US options
$0Free and open source, Apache-2.0

Settings

SettingDefaultRangeWhat it does
Expirations to project41–8Target horizons the cloud is drawn through: 4 is about 1 week, 2 weeks, 1 month and 2 months, plus the nearest expiry; 8 reaches about 3 months
Risk-free rate (%)4.00–15Discounting in the parity and pricing steps
Max bid-ask spread (fraction of mid)0.50.05–2Drops stale, illiquid quotes (a spread of $0.05 or less is always kept)
Min usable strikes per expiry85–60Skips expiries too thin to model
Show ForkOnOn / offHides the Fork marks and Fork line in the summary panel

Messages

Never a broken chart: it says why.

SituationWhat you see on the chart
Not a Daily chart“Implied runs on the Daily timeframe only.”
No listed options (crypto, most futures, forex), or no OPRA subscription“No options data for X. Implied needs a ticker with listed options and an OPRA subscription.” plus the data error, if any
No price history on the chart“Implied needs price history on the chart.”
An options request failsThe “No options data for X…” message, with the request's error in brackets
No expiration within reach“Options data for X did not include any expiration in the next 99 days.” (99 trading days in trading-day mode)
Every expiry too thin“Not enough liquid strikes on X to build a distribution.”
Some expiries thinThose are skipped; the rest still draw
